# 五本长篇样书 · 0.4

本轮按扩充示例书的要求，更新五本样书的正文、配置与共用新素材目录。`vault/books/ai-media`、其他笔记以及原有图片没有修改。

合计 51 章，新增 32 章，约 5.18 万中文字符（统计包括标题、注释、表格及章节配置中的中文）。各书独立写作，没有用循环复制段落或插入空白页增加篇幅。

- **内容的复利**：访谈、证据、长文编辑、渠道复用、社群知识、年度编书。
- **留一点时间思考**：八篇新随笔，包含连续叙事、书页意象、几何静物、四季记录与书信。
- **欲望制造**：虚构香氛品牌的定位、图像、文案、接触点、28 日发布日志与复盘。
- **生意的结构**：虚构工作室的需求、报价、产能、现金日历、客户回访与 20 项交接清单。
- **穿越波动**：资金约束、虚构路径比较、组合重叠、材料阅读、24 次观察记录与年度复核。

人物、经营事件、金额、工时与投资曲线为原创虚构或数学演示。投资一般概念的来源在章末标明；不使用实际交易建议、收益预测或真实业绩。

每本选一章使用 `layout: dense`：保留正文基准字号，PDF 的连续正文行距设为 1.65、段距收紧；正常图文页维持各自主题节奏。手机 HTML 与 EPUB 不强行套用固定纸张密度。

长目录自然跨页，仍保留可点击的实际 PDF 页码；A4 使用较紧凑的目录间距。表格由解析器区分短表与长表，防止长表被整块推到下一页并留下孤立标题。预览脚本改用章节书签定位页面，避免章节增加后继续引用旧页码。

## 看成品

构建后在本地打开 `exports/longform-review/index.html`。其中每本都有四张真实 PDF 样张，以及竖版、横版、A4、EPUB 与全书缩略图入口。页码与字数统计保存在同目录 `report.json`；PDF 正文片段检查在 `content-check.json`。

```bash
conda activate webproj
python scripts/publish.py build --all --profile all --epubcheck
python scripts/review_longform.py
python scripts/make_design_boards.py
python scripts/make_editorial_review.py
```

原稿直接在各书 Markdown 文件中维护。`scripts/make_longform_assets.py` 只重建新素材目录，不生成或覆盖书稿；普通构建无需运行它。素材数值记录位于 `vault/assets/longform-lab/data.json`。

预览与检查报告属于 `exports` 本地产物，不提交 Git。正式出版仍需人工编辑与逐页校对；这些是用于比较设计、检验长篇排版的样书。
