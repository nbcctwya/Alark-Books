# 项目整体复核 · 2026-09-28

## 当前状态

项目已形成可工作的多书、多主题出版流程：Obsidian 原稿 → 章节与资源解析 → 语义 HTML → 分页 PDF / 流式 EPUB → 预览与校验。六本示例书共 75 章，覆盖五个代码主题、六款视觉方案；现有产物包括 18 份 PDF 与 6 本 EPUB。

`vault`、`design`、`website`、`scripts`、`docs`、`exports` 的职责已经清楚。当前规模适合继续使用 Python、Jinja 模板与 CSS，不需要为目录组织引入前端框架或额外的内容数据库。`book.yml` 继续作为章节顺序的唯一配置。

## 设计判断

| 方向 | 当前定位 | 继续打磨的重点 |
| --- | --- | --- |
| 内容的复利 / editorial | 主力知识与商业内容书系 | 长篇阅读舒适度、章节起落、表格与图注的实际字号 |
| 留一点时间思考 / editorial | 随笔与轻量文字书 | 更细的段落节奏与章末留白 |
| 欲望制造 / spectacle | 传播与品牌专题 | 强烈页面之间的缓冲，连续阅读时的密度 |
| 生意的结构 / business | 方法、流程与经营案例 | 蓝色正文与图表在打印后的清晰度 |
| 穿越波动 / investment | 投资笔记与数据叙事 | 密集数字、脚注与来源的阅读体验 |
| 岸与间 / folio | 摄影、作品集与图片叙事 | 原图分辨率、裁切位置、组照比例与对页关系 |

优先将《内容的复利》和 FOLIO 作为两套主力：前者承担长篇文字，后者承担影像。现有其他主题继续提供明确的专题表达。下一阶段的投入应更多放到实际书稿的编辑与长篇稳定性上。

## 本轮已修复

1. **明确路径的错误回退**：原先带目录的图片或章节路径不存在时，解析器可能在全库找到同名文件后继续导出。现改为明确路径必须存在；只有无目录文件名保留 Obsidian 式查找。增加图片、章节两个回归用例。
2. **纸本与屏幕样式混用**：editorial 的手机宽度媒体查询产生 WeasyPrint 提醒。屏幕规则移至 `editorial-screen.css`，模板使用 `media="screen"`，纸本规则保留在 `editorial.css`。
3. **文档与实际主题不一致**：补全六本样书、五个代码主题和 FOLIO 配置说明，修正 README 中残留的五本书表述。
4. **复现步骤遗漏**：安装与复现步骤补上摄影集样张脚本，确保摄影集设计入口所需的实际 PDF 预览可以生成。

## 尚需安排的工作

1. **真实出版试稿**：选定一份将实际发布的书稿，集中处理目录层级、引用、图注、长表和章节收尾，逐页校对。
2. **终端与印刷验证**：使用实际 EPUB 阅读器测试字号与图片；需要纸质出版时再按印厂要求制定出血、颜色、装订与封面规格。摄影集的大图需要足够像素的原始摄影作品。
3. **交付与版本记录**：本地存在跨多轮工作的未提交变更，包括组织调整、样书扩篇与新主题。本轮没有提交或推送。发布前应把原稿、样式、脚本和说明作为可追溯的版本整理；`exports` 继续保持可重建且不入库。

预览脚本中的样书清单与部分章节名称目前仍是固定的，适合作为本项目的设计复核工具；普通用户书籍的构建并不依赖这些固定清单。若后续需要大量书籍的自动视觉回归，再把预览选择改为独立配置。
