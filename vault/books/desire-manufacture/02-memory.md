# 让人记住

一次夺目的展示可以成为开场，连续的表达则需要一些稳定的东西。对「无声剧场」来说，这些东西是黑色舞台、猩红丝带、银色反光，以及有明显停顿的短句。

每一张海报都可以变化，但变化应该围绕同一组视觉线索展开。今天出现完整瓶身，明天出现材质局部，后天只留下一个红色折面。它们需要像同一个故事里的不同镜头。

## 把识别做成约定

我们把视觉约定写成一张表。它帮助创作者判断新页面是否属于这套表达，也帮助协作者知道哪些地方可以自由发挥。

| 保留的线索 | 可以改变的部分 | 检查的问题 |
| --- | --- | --- |
| 黑、红、银的关系 | 三种颜色的占比 | 是否仍能辨认系列 |
| 一件明确的主角 | 全景、近景、局部 | 视线先落在哪里 |
| 短句与停顿 | 每次具体的文案 | 是否能够独立理解 |
| 统一的署名位置 | 图像构图与尺度 | 能否找到信息来源 |

## 重复，也要有新的信息

仅仅重复一个标志，会让内容变得单调。更有意义的重复，是让熟悉的形式承载新的细节。一次讲材料，一次讲制作过程，一次讲使用时的具体感受。

> 熟悉的轮廓，新的理由。

读者如果可以说出「这像你会做的东西」，说明视觉可能已经开始建立联系。还需要继续确认：这种联系是否准确，是否让人理解了你实际提供的价值。
