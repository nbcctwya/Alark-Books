# 回到自己的问题

我们接触的观点越来越多，真正能够反复使用的却往往只有少数几个。它们之所以留下来，是因为曾在具体情境里帮助我们做出判断。

## 把阅读带回行动

读完一段有启发的文字，可以试着写下一个实际应用场景。下次遇到类似问题时，先打开自己的记录，看看那段观点是否仍然适用。

如果适用，就记录一次新的验证；如果不适用，就补上边界。笔记因此不再只是储存别人的答案，也开始保存自己的思考过程。

> [!note] 一条可以持续使用的写作习惯
> 每篇笔记结束时，留下一个仍然愿意追问的问题。下一次回来，从它开始。

## 给未来的自己留下入口

链接的意义，是让两次思考能够相遇。这里可以回到[[01-space|关于留白的观察]]，重新理解为什么不完整的片段也值得保留。

写书也是这样的过程。章节之间会出现新的关系，先前的判断会被补充，某个原本不起眼的片段可能变成整本书的线索。允许修订，才有可能逐渐接近自己真正想说的话。

愿这些缓慢留下的文字，最终成为行动时的一点把握。
