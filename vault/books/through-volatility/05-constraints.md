# 先写下不能发生的事

一份投资记录可以从资产名称开始，也可以从生活中的一项安排开始。后者往往更难，因为它要求记录者说清楚这笔资金为什么存在、什么时候可能被使用、哪些变化无法承受。数字离开这些背景，容易看起来像一场单纯比较高低的游戏；放回背景之后，同一条价格路径对不同的人可能意味着完全不同的处境。

本章使用两位虚构记录者来讨论这个问题。甲为一年后的明确支出保留了一笔资金，乙记录的是暂时没有固定使用时点的一笔长期资金。他们看到相同的市场图表，却不应因此被假定拥有相同的选择空间。这里不提供具体配置建议，只展示怎样把目标、时间与限制写进一份可以检查的记录。

Investor.gov 的通识材料把投资期限与风险承受能力列为资产配置需要考虑的因素。[^allocation] 这不意味着填写一张表格就能获得适合自己的方案。表格只是把问题显露出来，实际决定仍然涉及个人处境、产品特征和必要的专业判断。尤其当资金与近期生活安排有关时，不能用一个抽象的长期平均值替代对使用时点的考虑。

甲最初写下“我能够接受波动”，后来发现这句话没有说明任何具体约束。如果支出日期不能改变，他是否仍然能够等待价格恢复？如果预计收入没有按时到达，是否会提前使用这笔资金？如果出现额外支出，其他资源是否可用？这些问题未必都能得到确定答案，但它们比一句笼统的风险偏好更接近实际决策条件。

## 意愿与能力不是同一个词

一个人可能在心理上愿意承担较大变化，却在现实中没有足够空间承受损失；也可能具备较长的资金期限，但看到价格变化时仍然难以保持原来的计划。把意愿与能力分开记录，有助于发现自我描述中的矛盾。不能因为自己在平静时写下了勇敢的话，就假定未来任何处境下都会按同样方式行动。

| 记录项目 | 需要说清楚的问题 | 不宜直接替代它的表达 |
| --- | --- | --- |
| 资金用途 | 最终准备支持什么安排 | 想让钱增长 |
| 使用时点 | 日期是否明确、是否可调整 | 打算长期持有 |
| 其他资源 | 出现变化时还有什么选择 | 应该总会有办法 |
| 损失影响 | 哪些安排会因此受影响 | 我能承受风险 |
| 重新检查 | 什么变化需要更新计划 | 到时候再说 |

## 从产品描述回到自身条件

一份产品材料可能讨论目标、历史表现、持有期限与风险，但这些信息并不会自动回答记录者自己的问题。阅读时可以把两张纸并排：一张是产品到底是什么，另一张是自己的资金需要什么。两张纸之间无法解释的部分，就是需要继续核对的位置。不要因为描述中出现了熟悉的词，就跳过理解具体机制。

## 给计划保留修订条件

甲与乙都为记录增加了“重新检查”一栏。不是要求价格每变化一次就重新作决定，而是提前说明哪些生活条件变化会影响原有计划，例如资金用途改变、使用日期提前或收入条件发生变化。这样，修订可以围绕真实约束展开，而不只围绕最近一次价格波动展开。

书面的计划也可能过时。旧记录的价值，不在于让人永远坚持，而在于让改变可以被解释。什么时候改了什么，为什么原来的假设不再成立，哪些部分仍然保留，这些信息能够帮助未来的自己区分有理由的调整与事后重写故事。

> 甲、乙与资金安排均为虚构。此处只演示记录方法，不据此推荐产品、仓位或交易时点。
