# 时间的坐标

同一条价格曲线，放进不同的生活安排里，会带来不同的问题。一笔近期需要使用的资金，与一笔可以长期保留的资金，其约束并不相同。讨论收益之前，先说明资金的用途和可能需要使用的时间，有助于理解后面的选择。

Investor.gov 的投资者教育材料把投资期限与风险承受能力列为理解资产配置的重要因素。分散投资旨在降低集中风险，但不能保证在市场下跌时不会发生损失。[^allocation]

## 把问题写完整

这本样书使用一个虚构的观察者：他不急着记录「应该买什么」，而是先写下资金可能在什么时候被使用、怎样理解损失，以及哪些假设还没有得到验证。这样的记录让日后回看时能够知道，判断是在什么前提下形成的。

| 记录维度 | 可以追问的问题 |
| --- | --- |
| 时间 | 这笔资金可能何时被使用 |
| 变化 | 哪些生活或收入变化会影响原先安排 |
| 承受能力 | 一次不利变化会带来哪些实际影响 |
| 理解程度 | 哪些产品特征和费用仍未弄清 |

## 给未知留下位置

写下不知道什么，是记录的一部分。一个暂时没有答案的问题，可以成为接下来阅读资料的方向。相比用确定的语气掩盖不确定，保留假设更有利于后续修订。

> 先说清楚坐标，再讨论向哪里走。
