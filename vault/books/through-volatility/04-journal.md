# 给判断留一本账

一份投资观察记录，可以同时保存当时知道的信息、尚未确认的假设和准备继续核对的问题。它不是为了把每一次判断都包装成正确，而是让变化发生之后，仍能看清自己曾经怎样理解情况。

## 分开写事实、解释与未知

事实是可以指向来源的材料；解释是自己对材料的理解；未知则是暂时无法确认的部分。把三者分开写，能够减少日后把新信息误记为「早就知道」的情况。

| 项目 | 记录方式 |
| --- | --- |
| 原始材料 | 来源、发布日期、观察范围 |
| 当前理解 | 这份材料可能意味着什么 |
| 关键假设 | 哪个前提改变后需要重读判断 |
| 未解问题 | 接下来还需要检查什么 |

## 回到可检查的问题

过一段时间再打开记录，可以问：哪些材料仍然有效？哪些假设已经改变？是否遗漏了费用、期限或数据口径？这样的一次回看，比只评价结果令人高兴还是失望，更容易留下可以继续使用的信息。

前面关于[[02-drawdown|回撤路径]]和[[03-cost|费用假设]]的演示，也可以作为检查记录是否完整的小练习。只看图表最后一个数字，往往看不到模型的边界。

> 把判断写下来，也把改变判断的条件写下来。

这本小书以一份尚未完成的观察记录收尾。时间还会继续，新的资料也会出现；留住当下的坐标，才有机会认真比较后来走过的路。
