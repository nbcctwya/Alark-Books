# 分散之前，先看重叠

一位虚构记录者列出自己关注的三个组合，把它们命名为甲、乙、丙。名称不同，介绍文字也不同，他因此以为它们代表三个彼此独立的方向。进一步查看示例构成后，发现它们都包含相同的一部分资产。这个发现没有直接告诉他应该怎样调整，却改变了问题：需要理解的是背后的暴露，而不只是外面的标签。

Investor.gov 的资料提醒，范围较窄的基金未必能提供期待中的分散效果，即使持有多个基金，也应检查主要持仓是否重叠。[^diversification] 本章只借用这一一般概念，下面的组合完全虚构，不对应真实基金，也不提供买卖建议。

设组合甲包含 X、Y 两项，权重各为百分之五十；组合乙包含 X、Z 两项，各为百分之五十。如果把同样多的资金分别放入甲、乙，在这个极简例子中，合并后的 X 占百分之五十，Y 与 Z 各占百分之二十五。表面上买了两个不同组合，仍然有一半集中在 X。所有名称都是占位符，没有行业或市场含义。

## 相关性不是一种永远不变的属性

不同对象的表现关系可能随条件变化。不能因为过去某段时间的曲线看起来不同，就假定以后总能相互抵消。这里不估计具体相关系数，也不作市场预测，只提醒记录者不要把有限观察写成永久关系。分散有其用途，同时也不能保证避免全部损失。

对普通阅读者而言，可以先做一项较简单的工作：把自己理解的风险来源写出来，并标明哪些只是产品名称带来的印象，哪些来自实际资料。若仍然无法解释某个对象怎样产生回报、可能在哪些条件下受损，就把它列为需要进一步理解的部分，而不是用“与其他不同”来代替解释。

| 层次 | 示例问题 | 容易混淆的地方 |
| --- | --- | --- |
| 名称 | 产品叫什么 | 不同名称不等于不同持仓 |
| 构成 | 里面实际持有什么 | 包装描述不等于完整构成 |
| 机制 | 收益与损失怎样产生 | 历史曲线不等于机制说明 |
| 条件 | 在什么变化下可能受影响 | 不同类别也可能共同受冲击 |
| 自身用途 | 与资金安排是否相容 | 分散概念不自动给出个人方案 |

## 把未知放进记录

记录者为三个组合画了一张关系图，发现自己对丙的理解最少。他没有把空白处随意填上“低风险”，而是写下尚未理解的机制。这种记录看起来不够完整，却比用一个熟悉标签遮住陌生对象更可靠。投资中的不确定性已经很多，没有必要再增加对自己理解程度的误判。

## 复核需要一个时间戳

构成信息可能改变，旧记录应当说明取得日期和资料范围。一本年鉴式的笔记不能只保存结论，也要保存结论基于哪一版材料。未来重新阅读时，才能知道某个判断是当时资料支持的结果，还是后来情况变化后已经失效的描述。

> [!note] 示例口径
> 组合权重仅用于加权计算，忽略费用、价格变化与其他事项。它展示重叠怎样发生，不构成分散配置方案。

[^diversification]: Investor.gov，Asset Allocation and Diversification，https://www.investor.gov/introduction-investing/getting-started/asset-allocation ，查阅于 2026-09-27。
