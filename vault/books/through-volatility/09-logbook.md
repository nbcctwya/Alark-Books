# 二十四次记录，而不是二十四次交易

下面是一份虚构的观察日志。它故意不记录具体买卖，也不以价格变化作为每天必须行动的理由。日志的对象是判断过程：今天新增了什么材料，原来的假设是否真的改变，哪些反应来自情绪，哪些问题需要进一步核对。书写的频率与交易的频率是两回事，不应在版面上被暗示为同一件事。

记录者最初每天只写“看涨”或“看跌”，很快发现这些词几乎无法帮助自己复盘。即使后来方向碰巧正确，也不知道当时的理由是否可靠；即使结果不符，也无法判断究竟是哪一个假设出了问题。于是他改成描述具体观察，并把行动留给另一个需要单独解释的决定过程。

## 观察册摘录

| 记录 | 新出现的材料或反应 | 留下的核对问题 |
| --- | --- | --- |
| 01 | 看到一张没有区间说明的曲线 | 起终点为什么这样选择 |
| 02 | 发现两份资料使用不同口径 | 是否包含相同现金流 |
| 03 | 想因为一天的变化重写计划 | 资金用途是否真的改变 |
| 04 | 一段解释与原先判断一致 | 是否主动寻找了反例 |
| 05 | 找到原始文件的更新版本 | 哪些旧记录需要修订 |
| 06 | 无法用自己的话解释机制 | 缺少的是术语还是过程 |
| 07 | 把一次结果当作方法证明 | 是否存在其他解释 |
| 08 | 对一个整数目标产生执着 | 这个数字来自哪里 |
| 09 | 忽略了材料里的费用说明 | 比较是否使用相同条件 |
| 10 | 朋友的经历影响了自己的预期 | 两人的约束是否相同 |
| 11 | 发现组合之间存在重叠 | 名称以外的构成是什么 |
| 12 | 记录了一个极端情景 | 情景与发生概率是否混淆 |
| 13 | 旧结论只剩一段摘要 | 是否还能找到原始依据 |
| 14 | 想用更多信息消除所有不确定性 | 哪些未知本来无法消除 |
| 15 | 一份资料没有标明日期 | 信息是否仍然适用 |
| 16 | 注意到自己只保存正面消息 | 收集过程是否存在偏向 |
| 17 | 现金使用日期发生变化 | 哪些原有假设需要检查 |
| 18 | 某个观点变得很流行 | 流行是否增加了实际证据 |
| 19 | 用期末结果评价全部过程 | 途中约束是否被忽略 |
| 20 | 对一段损失经历记忆模糊 | 当时记录是否仍然完整 |
| 21 | 发现自己的解释过于复杂 | 是否在替旧判断寻找理由 |
| 22 | 一项问题需要专业知识 | 适合向谁寻求说明 |
| 23 | 暂时没有足够材料 | 能否诚实地保持未决定 |
| 24 | 回看整本日志 | 哪些问题反复出现但从未处理 |

## 记录也可能成为负担

如果写日志只是让人更频繁地盯着变化，它未必帮助理解。可以检查记录是否产生了新的可核对信息，还是只在重复当天的感受。感受值得被记录，但不必每次都被包装成新的判断。减少无意义的更新，有时比增加记录字段更有帮助。

## 保留当时的语气

事后整理容易让过去看起来比实际更清楚。一个犹豫的判断被改成坚定的观点，一个偶然结果被写成早有准备的选择，复盘就失去了重要材料。可以添加后续说明，但尽量保留当时的原始记录与日期。让“那时知道什么”和“现在知道什么”同时存在，才能看见认识发生变化的地方。

> [!note] 日志用途
> 本表为原创虚构的阅读与反思练习，不是交易计划，也不暗示某种记录频率适合所有人。
