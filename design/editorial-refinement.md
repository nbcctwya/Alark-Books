# 主力书系 · 内页打磨

以《内容的复利》作为 AIark / Alark 的主力编辑方向。保留自然纸白、宋体阅读与海岸摄影封面，重点建立可复用的内页节奏。本轮没有修改 `vault` 的任何文件。

## 本轮改动

- **目录成为阅读索引**：复用原稿已有的章节副标题，帮助读者理解各章线索。章节之间以细线区分，保留实际页码与点击跳转。
- **统一章节开篇**：小章号位于左侧，章名和引导语组成正文入口，细顶线建立稳定的位置关系。
- **摄影与引文共同落版**：原稿中相邻的引用与图片组合为图版。竖版上下排列，横版采用左侧引文、右侧摄影，避免两者被分页拆散。
- **短表完整、长表连续**：含表头不超过九行的短表尽量保持同页；长记录表继续跨页并重复表头。缩小单元格内边距，保持字号可读。
- **收紧注释与图表的关系**：图注使用辅助黑体，缩短注释分隔线间距，横版限制通栏图表高度，避免注释单独占页。
- **屏幕与 EPUB 同步**：手机保留单栏，横版摄影组合在窄屏上下排列；EPUB 保持流式字号，采用对应的细线和标题层次。

## 实现位置

`website/styles/editorial.css`、`editorial-epub.css` 是主力书系的独立样式；基础 `book.css` 继续提供各主题共享规则。`book.html.j2` 使用现有原稿字段生成目录与开篇。图文分组只作用于复制后的渲染文档，不写回原稿。

《留一点时间思考》共享目录与章节体系，以纯字体封面维持随笔气质。商业、投资与奢华主题的样式保持独立。

## 查看与复现

本地打开 [实际书页预览](editorial-refinement.html)。预览图来自真实 PDF，没有另行绘制页面。

```bash
conda activate webproj
python scripts/publish.py build layout-lab --profile all --epubcheck
python scripts/publish.py build field-notes --profile all --epubcheck
python scripts/make_editorial_review.py
```

此前 PDF 的副本仅保存在本地 `exports/visual-review/editorial-before/`，用于本轮对比，不属于可复建的原稿。预览脚本没有旧 PDF 时仍可生成新版对页。

## 后续方向

现有书稿仍含排版压力测试章节；未通过修改内容制造更好的页面效果。下一步真正值得投入的是长篇正文的编辑、更多具有叙事作用的摄影、案例与访谈等内容类型，再据此扩展版式。正式出版前仍需逐页人工检查，自动分页不等于完成编辑设计。
