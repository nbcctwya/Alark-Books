# FOLIO · 影像札记

专为摄影集、作品集、旅行影像与图片为主的书设计。示例书《岸与间》位于 `vault/books/shore-and-space`，包含 24 章、20 张独立影像，个别图片在对照页与札记中有意重现。

[实际书页预览](folio.html) · [原稿](../vault/books/shore-and-space/) · [素材与提示词](../vault/assets/shore-and-space/SOURCE.md)

## 视觉语言

- **纸面**：纯白，墨灰正文，冷灰编号。照片之外不加纸纹、装饰网格、圆角或卡片阴影。
- **文字**：宋体标题与随笔，无衬线编号和图注。标题退让给图像，图注跟随图片，不单独漂到下一页。
- **画幅**：默认保留原图比例，竖图不再沿用文字书的小图侧栏。封面及明确指定的满版页可中心裁切。
- **节奏**：横幅景物、竖幅建筑、双图和组照交替；少量图文随笔承担阅读停顿。满版页只用于少量视觉重点。
- **对页**：按照实际相邻偶数页、奇数页组合审阅，不把任意两页拼成虚假的跨页效果。当前不把同一图片切成左右两张跨书脊输出。

## 五种版式

在书籍 `book.yml` 设置 `design: folio`，章节 frontmatter 设置 `photo_layout`：

| 配置 | 用途 | 原稿约定 |
| --- | --- | --- |
| `plate` | 单幅大图与短文，默认 | 每张图片单独成段，图注写在图片替代文字里 |
| `pair` | 两幅图并置 | 连续图片每两幅组成一组；正文会中断分组 |
| `contact` | 四幅组照 | 连续图片每四幅组成一组，超过四幅自动另起一组 |
| `essay` | 图文随笔 | 图片靠右，文字环绕；手机上恢复正常顺序 |
| `bleed` | 满版强调页 | 章节正文必须只有一张独立图片，说明放入图注；标题、图注位于页底 |

最后一组允许不足两幅或四幅，不补空白图片。图片可以使用普通 Markdown 或 Obsidian 图片链接。组图仅改变排版容器，不改变图片、图注、正文、链接的顺序。满版严格限制正文，避免内容被固定页面裁掉。长标题和长图注仍应逐页复核。

```yaml
# book.yml
design: folio
theme: forest
cover_image: assets/my-album/cover.jpg
cover_alt: 海面上的清晨
cover_credit: 摄影：作者姓名
```

```markdown
---
title: 房间里的远方
subtitle: 同一种蓝，两种距离
kicker: INTERIOR
photo_layout: pair
---

# 房间里的远方

![[assets/my-album/window.jpg|01 / 窗。拍摄地点与时间。]]

![[assets/my-album/curtain.jpg|02 / 帘。拍摄地点与时间。]]

少量文字记录这两幅图之间的关系。
```

`kicker`、`subtitle` 均可省略。图注应简短，图片替代文字也会成为 EPUB 的可访问描述。长篇说明放在普通段落或 `essay` 章节。

## 三种纸面与 EPUB

竖版适合手持阅读与竖幅作品；横版单图页采用大图与短文左右排布，并采用左右分置封面；A4 适合大图审阅。默认尺寸沿用项目配置，图片尺寸随主题适配。

EPUB 为流式版本，全部图片保持完整比例，双图和组照按顺序展开；不强制保留纸本满版裁切。可以调字号、调整阅读器视口，章节导航和图注照常保留。固定版式 EPUB 不在本主题实现范围内。

## 影像来源与印刷边界

二十张图均由内置 imagegen 生成，地点为虚构，未附会真实拍摄者、拍摄地点或 EXIF 参数。原始 PNG 保存在 `vault/assets/shore-and-space`，完整提示词在同目录 `SOURCE.md`。没有把放大插值当成新增摄影细节。

原图为 1536×1024 或 1024×1536 像素，部分大幅页面低于现有 250 DPI 检查阈值，构建报告会保留分辨率提醒。本样书用于数字阅读和版式审阅；正式大幅印刷应换入高分辨率原片，并依印厂要求另行处理出血、颜色和装订。满版 PDF 当前是成品尺寸页面，不含印厂出血。


## 0.2 扩篇：从海岸到色彩

新增十二章、十张图，插入原有暮色章节与后记之间，后记仍然位于全书末尾。影像顺序从黑白形状进入浓色，再经过夜景、清亮水色、森林和粉彩地景，最后落到运动模糊与蓝晒风格习作。新增色彩组照和长篇编辑札记，讨论相邻图像的色彩、明暗、纹理与观看距离。

新增图片全部为 AI 生成原图，包括工艺与运动模糊的视觉模拟，不宣称真实拍摄或实际蓝晒制作。原有十张图未做滤镜处理。预览脚本新增三种尺寸的 `*-color-board.png`，展示扩篇的十二个章节。

扩篇版最终输出：竖版 31 页、横版 30 页、A4 28 页，EPUB 24 章。三份 PDF 保留原始图像分辨率提醒，文字与图注完整性检查通过。
