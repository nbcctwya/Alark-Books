# 纸本与摄影刊物方向 · v0.2

根据「更像书本、摄影杂志」的反馈，2026-09-27 将实际出版模板调整为纸本编辑风格。修改同时进入 PDF、EPUB、HTML 阅读版与作品书架。

## 本次取舍

- 书名、章节、小节、正文采用宋体，辅助信息使用少量黑体。
- 内页接近自然纸白，以暖黑印刷文字建立对比；正文首行缩进两字，段间留白收紧。
- 章节首页用小编号、标题和引导语建立层次；目录靠标题、页码与留白组织。
- 页眉和页码位于翻开书的外侧；取消版式名称等技术标签。
- 提示块改成细线上下分隔的编辑旁注，表格采用白底细线，取消彩色导航条、大编号和成片底色。
- 摄影图成为封面和正文的重要组成；图注与图像分离，保留来源说明。
- 书架改用纸本文字目录的呈现，阅读 HTML 使用连续纸面。

## 两本样书

《内容的复利》使用摄影式封面：文字在上、图像在下，横版则将图像置于右侧，与标题形成对照。原有方法图、数据图继续保留。

《留一点时间思考》使用纯字体封面，以书名、作者、出版署名与留白形成随笔集的安静气质。

旧版的三份主要 PDF 保留于 `exports/archive/v0.1/`。新版仍写入原来的输出目录，阅读入口为 `exports/index.html`。

## 为自己的书指定封面

在 `book.yml` 中添加：

```yaml
cover_image: assets/my-book/cover.jpg
cover_alt: 对封面图像的简短描述
cover_credit: 摄影者姓名与授权说明
```

图片必须放在 `vault/assets`，封面支持 PNG、JPEG。缺省时生成纯字体封面。封面按版式裁切，正文图片保持比例；选择主体周围有留白的图像更易适配不同开本。大标题和较长副标题仍需查看实际 PDF。

## 输出性质

这次调整针对装帧与阅读风格。PDF 仍为 RGB 数字阅读版本；真实纸张的手感、印刷网点、装订与书脊要在实体制作时确定。
